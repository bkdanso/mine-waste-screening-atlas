# Next steps (after v0.1.0)

*Plain-language note: what a later version adds, so v0.1 is understood as a first step.*

1. **Waste-only index.** A second Critical Mineral Index that uses only samples taken on mine waste, for the features that have them.
2. **New inventory versions.** Rerun when USGS releases NMWI v3 and add new states; Zenodo versioning keeps one DOI for all versions.
3. **State characterization data.** Compare rankings with Earth MRI state-survey sampling results as they are published (a true field check).
4. **Contained metal.** Where NMWI resource fields give tonnage, estimate contained metal (tonnage times grade) for the leading elements.
5. **Local background.** Replace the national soil median with nearby non-mining samples for each district.
6. **Watershed link.** Join features to downstream stream-sediment and water samples to connect pile hazard with watershed exposure.
